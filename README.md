# PHP to Enterprise CRUD Reference Repo

Этот каталог зарезервирован под отдельный git-репозиторий курса.

Предлагаемый удаленный репозиторий:
- `php-to-enterprise-crud`

Предлагаемая схема веток:
- `main` — стартовая база проекта;
- `homework-*` — эталонные решения домашних заданий;
- `exam-*` — экзаменационные сценарии.

Сквозной проект:
- `NSI management system`
- сущности: `products`, `categories`, `units`, `suppliers`

Среда:
- Docker-окружение из курса `docker-engineering-environment`
- `PHP` / `Laravel` baseline будет зафиксирован после создания репозитория
